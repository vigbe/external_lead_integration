External Lead Integration

Turn any website form into a CRM lead — a secure REST endpoint for Odoo

Developed by vicbas.com

Key Features

API-Key Authentication

Each integration gets a secret key sent in the X-API-Key header. Keys are stored as SHA-256 hashes — the plaintext is never persisted.

Real HTTP Semantics

A public endpoint that answers with real status codes (201 created, 200 duplicate, 400/401/422/500) and a JSON body — no Odoo session required.

Configurable Defaults

Default sales team, salesperson, stage, source, campaign and contact-info requirements are set in Settings and applied to every lead.

Per-Key Overrides

An API key can force its own sales team and salesperson, so each website or landing page routes leads exactly where you want.

Smart Deduplication

Optional email-based duplicate detection: repeated submissions return 200 with the existing lead instead of creating noise.

CORS Ready

A configurable origin allowlist lets browser forms read the responses directly, with preflight handled for you.

How It Works

1. Generate a key

CRM → Configuration → External Lead API Keys. The secret is shown once in a copyable wizard.

2. POST your leads

Your website sends JSON to the endpoint with the X-API-Key header — from any form, framework or marketing tool.

3. Lead in your CRM

The lead is created instantly with your defaults: team, salesperson, stage, source and campaign.

Security First

Keys are stored as SHA-256 hashes: the full secret is shown exactly once, then only a masked value is displayed. Regenerate to rotate a key at any time, or archive it to revoke access instantly. Legacy plaintext keys are migrated to a hash automatically on their first successful request. As with any public endpoint, keep it behind a reverse proxy with rate limiting and abuse protection (e.g. reCAPTCHA) at the edge.

Compatibility

Published for Odoo 16.0, 17.0, 18.0 and 19.0 — Community and Enterprise. Depends only on base and crm: optional real-estate fields are mapped only when they exist in your database, so the module works with a plain CRM out of the box.
