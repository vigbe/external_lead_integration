External Lead Integration

A versioned REST endpoint that lets external websites, landing pages and forms create CRM leads in your Odoo — no user session needed.

Developed by vicbas.com

$9.99 · one-time per Odoo database

What it does

One endpoint for every site

POST /api/v1/leads with a JSON body and an X-API-Key header. Your landing pages, marketing forms or backend services create leads directly in Odoo.

API-key authentication

Each integration gets its own secret key, stored as a SHA-256 hash (plaintext never rests in the database), shown once, and rotatable.

Clean, attributed leads

Team / salesperson / stage / campaign come from your configuration — request bodies cannot inject attribution. Optional email dedup keeps the pipeline tidy.

How to use it

Integration in four commands:

  1. Install the module
    Standard Community dependencies only (crm).
  2. Generate an API key
    Settings → External Lead API Keys → New. The plaintext key is shown exactly once in a copyable dialog — store it in your site's secrets.
  3. Configure the defaults
    In Settings pick the default sales team, salesperson, stage, source/campaign, whether contact info is required, and whether to deduplicate by email.
  4. POST your leads
    Point your form/backend at https://your-odoo/api/v1/leads with header X-API-Key and a JSON body (name, email, phone, message, title…).
  5. Read the response
    201 created · 200 duplicate (dedup on) · 400/401/422 validation, auth or key errors — always a JSON body, never HTML.

Example

curl -X POST https://your-odoo/api/v1/leads \
  -H 'Content-Type: application/json' \
  -H 'X-API-Key: oo_xxxxxxxxxxxxxxxx' \
  -d '{"name": "Jane Doe", "email": "jane@example.com", "message": "I want a quote"}'

Key features

Feature Detail
Per-key overrides A key can force a specific sales team / salesperson for one site while others use the global defaults.
Hashed keys + rotation Keys hash to SHA-256, support regeneration, archiving and lazy migration of legacy plaintext keys.
Deduplication Optional: same email → returns the existing open lead instead of creating a duplicate.
Group-restricted management Dedicated External Lead Admin group guards key management.
Multilingual UI English + Spanish (es, es_CL) translations included.
